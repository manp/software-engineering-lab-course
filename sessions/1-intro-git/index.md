# جلسه ۱ — گیت، GitHub و رپازیتوری تست

📅 **موضوع جلسه:** آشنایی اولیه با کنترل نسخه و راه‌اندازی اولین مخزن روی GitHub

## 🎯 اهداف جلسه
- درک مفهوم **گیت (Git)** و **رپازیتوری (Repository)**
- ساخت حساب کاربری در **GitHub**
- ساخت یک **رپازیتوری تست** به‌صورت عملی

## 📚 تاپیک‌های این جلسه

| # | تاپیک | فایل | خلاصه |
|---|---|---|---|
| ۱ | آشنایی با گیت و رپازیتوری | [مشاهده](01-git-intro.md) | گیت چیست، رپازیتوری چیست، نصب و تنظیم اولیه و دستورهای پایه |
| ۲ | ساخت حساب کاربری در GitHub | [مشاهده](02-github-account.md) | ساخت حساب، تنظیمات پروفایل و اتصال امن به گیت |
| ۳ | ساخت رپازیتوری تست | [مشاهده](03-test-repo.md) | ساخت مخزن روی GitHub، اتصال با گیت و اولین commit |
